# FreelanceHub - Fiverr Clone

Full-stack MERN freelance marketplace with OTP auth, messaging, and Razorpay payments.

## Setup

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Open http://localhost:5173

## .env (server/.env)
Already configured with your credentials. Replace Razorpay keys with real ones from razorpay.com
